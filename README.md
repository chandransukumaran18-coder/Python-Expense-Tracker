# Python-Expense-Tracker
A Python-based Expense Tracker application that helps users record, manage, and analyze daily expenses using a MySQL database. The project provides a simple command-line interface to perform CRUD operations such as adding, viewing, searching, and deleting expenses. 

---

##  Features

-  Add new expenses (amount, category, description, date)
-  View all recorded expenses
-  Search expenses by month and year
-  Delete expenses using unique ID
-  Monthly expense summary
-  Visualize daily spending trends using graphs
-  
---

##  Technologies Used

- Python  
- MySQL   
- Matplotlib   
- NumPy   
- MySQL Connector (Python integration)
